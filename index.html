What the evidence says

Naming rules & restrictions

Officially documented facts are separated from community claims and technical caveats.

Official support

Rename Card required

PUBG MOBILE Help Center says an in-game nickname can be changed using a Rename Card. Its current help article describes obtaining one through Growth Missions or the Shop.

Official support

Daily rename limit

The Help Center says a Rename Card can be used to change the nickname once per day. Check the live in-game instructions because features can change.

Developer statement

Numbers-only names

In a developer talk, PUBG MOBILE said it would prevent nicknames consisting only of numbers. This is not a ban on using digits alongside letters.

Official rules

Inappropriate names

PUBG MOBILE rules prohibit offensive or inappropriate content. Names may be acted on if they are abusive, sexually explicit, discriminatory, impersonate staff, or create other prohibited impressions.

Not officially specified

Maximum length

A universal character limit and the exact counting method are not clearly stated in the official help page. Online claims such as “14 characters” should be treated as practical reports, not a guaranteed official specification.

Not officially specified

Spaces & punctuation

There is no complete official public character whitelist. A symbol's presence in Unicode does not prove the PUBG nickname field accepts it. Test the exact name in-game.

Not officially specified

Emoji & invisible characters

Emoji, zero-width characters and unusual formatting marks may be rejected, stripped, counted unexpectedly or render differently. This library does not recommend relying on invisible characters.

Important distinction

Unique name availability

A character-valid nickname may still be unavailable or blocked. Character acceptance, name availability and policy compliance are separate checks.

Technical reference

Why some fancy characters fail

Unicode is not the same as PUBG compatibility

Unicode assigns code points to characters across writing systems and symbol blocks. The game decides which input it accepts, how it counts the name, and which fonts are available to display it.

Three ways text can be counted

  • Code points: Unicode character values.
  • UTF-16 code units: A common programming representation; some characters use two units.
  • Grapheme clusters: What people perceive as one displayed character; a combined emoji can contain several code points.

This page shows visible-character count and JavaScript UTF-16 units as an educational estimate. PUBG may use a different validator.

Unicode normalization

Compatibility normalization such as NFKC can convert some styled characters to ordinary letters. There is no confirmed public statement that PUBG MOBILE applies NFKC to every nickname.

Quick checklist

Before you confirm a rename

  • Keep the name respectful and avoid offensive, discriminatory or impersonating content.
  • Do not use a numeric-only nickname.
  • Paste the exact final name into PUBG MOBILE's rename field and check whether it is accepted.
  • Check how it appears on your own device and, if possible, another device.
  • Remember that a name can be accepted by the input field but still be unavailable or subject to moderation.
  • Confirm the name before consuming a Rename Card; the official Help Center describes a once-per-day rename limit.
